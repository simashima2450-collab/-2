# 架空物件 実験用ページ

GitHub Pages 用の静的サイトです。外部の画像配信や JavaScript に依存しません。

## アップロード

このフォルダー内の `index.html`、3つの物件ページ、`styles.css`、`assets` フォルダーを、同じ階層のまま GitHub リポジトリの公開元（通常はルート）へアップロードしてください。Settings → Pages で `Deploy from a branch`、`main`、`/ (root)` を選ぶと、数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

実験協力者には、目次ではなく該当する物件ページの URL を直接渡せます。各ページから別条件へ移動するリンクは置いていません。

| ファイル | 内容 |
|---|---|
| `general.html` | 一般型、賃料非表示、川崎市宮前区の架空物件 |
| `narrative.html` | 文章型、賃料非表示、江東区の架空物件 |
| `price.html` | 賃料表示、杉並区の架空物件 |

３物件は架空です。実在する自治体・町域・駅を使っていますが、建物、室内、間取り、設備、賃料、徒歩分数は実在物件の広告情報ではありません。画像は各物件用に新規生成したパースです。寸法を保証する実測図ではないため、間取り図は「模式図」と記しています。

一般型の情報項目は [SUUMO の賃貸物件詳細](https://suumo.jp/chintai/) を、文章型の紹介順は [東京R不動産](https://www.realtokyoestate.co.jp/) を参考にしています。ロゴ、文章、写真、固有のデザインは複製していません。
