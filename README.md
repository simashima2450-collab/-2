# HTMLの配置

次の5ファイルを、GitHub Pagesの公開元の同名ファイルへ上書きしてください。5ファイルは同じ階層に置いてください。

- index.html：表紙
- general.html：文章なし・価格非表示
- narrative.html：文章あり・価格非表示
- price.html：価格を表示する参考物件
- survey.html：Googleフォームへのアクセスページ

写真・図面・CSS・ページの移動処理をHTML内に埋め込んでいます。assets、previewsや補助スクリプトは、公開のためにアップロードする必要はありません。

表紙から「次へ」を押すと、3物件をランダムな順序で各1回表示します。順序はURLに保持され、途中の再読み込みでも変わりません。3物件を見終えるとアンケートアクセスページへ進みます。表紙から再開始すると、新しい順序を選びます。

## 物件設定と画像について

3物件は研究用の架空の中古マンションです。所在地の町域・駅は実在しますが、住所内の特定の実物件を再現していません。面積・築年・費用・販売価格・徒歩分数・管理条件は設定値です。価格表示物件の販売価格は5,280万円です。ほかの2物件の販売価格は表示していません。

図面はオリジナルのSVGで、外壁、間仕切り、建具、窓、収納、水回り、方位、目安寸法を表示しています。帖数と寸法は目安で、施工図ではありません。パースは図面の部屋の関係や開口を参照した生成画像です。寸法や細部の納まりを厳密に再現する図面ではありません。

画像は組み込みの画像生成機能で作成しています。render-prompts.json に各視点の生成条件を収録しました。assets 内に画像原稿のJPEG、previews 内に図面原稿と一覧を同梱しています。
