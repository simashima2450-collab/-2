# 番号で6通りに振り分ける実験サイト

## 配置

ZIP内の22個のHTMLファイルを、GitHub Pagesの同じ階層にアップロードしてください。入口はindex.htmlです。写真、図面、CSS、ページ移動のJavaScriptはHTMLに埋め込んであります。plans、JSON、READMEは公開のためにアップロードする必要はありません。

旧サイトのindex.htmlとsurvey.htmlを上書きすると入口と最終ページが変わります。

## 流れ

1. 扉ページで名前と番号を入力します。タイトル・案内文は従来のものを引き継ぎ、物件数を6件に変更しました。
2. 番号を6で割った余り（0〜5）と同じ番号のまとめページへ進みます。例：番号12→summary-0.html、番号13→summary-1.html。先頭の0、全角数字、大きい番号にも対応します。負数・小数・文字を含む番号は受け付けません。
3. まとめページのサムネイルから、基準2件と検討物件4件を開きます。各物件には「まとめページに戻る」があります。
4. 閲覧後、まとめページの「次へ」でアンケートアクセスページへ進みます。最終ページから同じ6ページを見直すこともできます。

番号の余りで条件を決めるので、同じ番号ではいつも同じ条件です。再読み込み・再閲覧でもランダムに変更されません。対象者間の人数均等化は、番号の配布方法で調整してください。

- 街の余韻をほどく窓辺（野毛）：4,680万円

どの通りでも、基準2件は同一HTMLを参照するため、写真・図面・物件情報・価格が共通です。野毛の物件が追加の基準です。販売価格や諸条件は研究用の架空設定で、市場査定ではありません。

同一物件の文章あり・なしでは、写真5枚、図面、物件名、基本情報、詳細情報が共通です。文章ありは約1,000字の紹介文、文章なしは客観的な物件情報のみです。どちらも販売価格は「＊＊＊＊万円」と表示します。基準2件のみ実額を表示します。写真の注釈は写真の外側・下段の右寄せとし、サムネイルには注釈を載せません。まとめページ・最終ページの各サムネイルには、物件情報の右側に、その物件の間取り図を掲載しています。写真はクリックで拡大できます。

## 名前と番号

名前と番号は、入力した端末のタブ内のsessionStorageにのみ保持します。名前・元の番号をURLへ付加せず、サーバーにも送信しません。URLで受け渡すのはページ番号0〜5だけです。これらの入力をGoogleフォームへ自動転記する機能は今回実装していません。

## アンケート

最終ページの「アンケートへ」は既存のGoogleフォーム回答用リンクです。Googleフォーム自体は変更していません。従来の物件名が固定された設問・戻りリンクを、今回の6物件とページ番号に対応させる調整が、本番の回答収集前に必要です。名前・番号・ページ番号を回答に記録する場合も、フォームに設問を設けてください。

## 図面編集

plans内に6物件それぞれのベクターPDFとSVG原稿を同梱しています。別途提出するfloor-plans-six-editable.pdfは、基準2件→検討4件の順の6ページ版です。PDFに画像を貼ったものではなく、線・面・文字をベクターで収録しています。編集アプリによって文字の再編集方法が異なるため、文字を扱いやすいSVG原稿も収録しました。

図面は研究用の架空の計画で、寸法・帖数は目安、専有面積は設定値です。施工図ではありません。パースは空間イメージで、細部の納まりや寸法を厳密に再現するものではありません。PDF・SVGを編集しても、HTML内に埋め込んだ図面は自動更新されません。

## 軽量版（2026-10-14）

HTML形式・ページ構成・写真の構図・文章・条件割当・リンク・サムネイル内の間取り図はそのままです。写真は長辺最大1280px、一覧用は最大560pxに縮小し、WebPとしてHTML内へ埋め込んでいます。画像フォルダーのアップロードは不要です。画像の拡大表示も利用できますが、原稿画像より解像度は低くなります。重複する画像原稿はZIPから除き、編集用図面は残しています。
