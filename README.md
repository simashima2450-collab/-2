# 修正間取りに合わせた実験サイト

## アップロード
ZIP内の22個のHTMLを、GitHub Pagesの同じ階層へ上書きしてください。入口はindex.htmlです。写真・間取り・スタイル・JavaScriptは各HTMLに埋め込まれているため、画像フォルダーの追加アップロードは不要です。

## 構成
実験参加番号を6で割った余りでsummary-0.html〜summary-5.htmlへ進みます。基準2件と、文章あり2件・文章なし2件の条件は番号ごとに固定です。6物件の一覧配置は初回にランダムにし、同じタブ内の再閲覧と最終ページで維持します。価格は基準2件のみ実額を表示し、残る4件は「＊＊＊＊万円」です。氏名は収集しません。

## 今回の更新
ご提供の「間取り1.pdf」全6ページを基準に、6物件×5枚のパースを新たに制作しました。間取り自体の形状・壁・開口・設備の配置は編集していません。サムネイル、物件ページ、拡大図は提供PDFの該当ページをそのまま画像へ変換して掲載しています。図面の編集原稿はplans/floor-plans-supplied.pdfです。原本と同じ内容で、ページ順は西荻北・野毛・土橋・清澄・大田・希望ヶ丘です。各ページを変換したSVGもplansに同梱しています。写真は軽量化して埋め込み、画像の拡大表示も利用できます。画像は空間のCG表現で、設備製品や細部の形状は模式的です。
